# Liftbay agent skills

Skills that teach coding agents (Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf and others) to build, sign, submit and update React Native and Expo apps with [Liftbay](https://liftbay.dev).

```sh
npx skills add liftbay/skills
```

Add `-g` to install for all your projects, or `--all` to install for every agent on this machine.

| Skill | What it does |
|---|---|
| [`liftbay`](skills/liftbay/SKILL.md) | Sign in, link the app, signing, iOS and Android builds, TestFlight and Google Play, ad hoc installs, OTA updates |

The skill drives the [Liftbay CLI](https://github.com/liftbay/cli). Guide: https://liftbay.dev/docs/agents

This repository is published from the Liftbay monorepo; open issues here.
